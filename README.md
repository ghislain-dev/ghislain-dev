## 👨‍💻 À propos de moi

Je suis un développeur passionné par la création d’applications web modernes, dynamiques et utiles.  
Je travaille principalement avec **PHP, MySQL, HTML, CSS, Bootstrap et JavaScript**.

J’aime développer des solutions de gestion, notamment pour les boutiques, les stocks, les paiements, les inscriptions et les systèmes administratifs.

---

## 🚀 Ce que je fais

- Développement d’applications web
- Conception de bases de données
- Création de tableaux de bord administratifs
- Gestion de stock et ventes
- Authentification et gestion des rôles
- Développement backend avec PHP / MySQL
- Interfaces modernes avec HTML, CSS, Bootstrap
